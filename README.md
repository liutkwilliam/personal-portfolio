# William Liu's Portfolio

This is the working repository of my creative technology portfolio. The current version of this portfolio is built with reactJS, ViteJS, TailwindCSS and Firebase, applied with RESTful API in connecting the database, to display my wonderful technical and design projects on my custom built web-app style portfolio, leveraged AI-assisted workflows through CodeX and Gemini to accelerate the development.

## Website Design History / Journey

- Nov 2019: This portfolio was first built using HTML, CSS, JS and Jekyll static-site builder.
- Oct 2020: Upgraded the portfolio with refreshing design and using Bootstrap styling
- Apr 2023: Improved with various portfolio
- June 2026: Redesigned the website into a modern website with reactJS, ViteJS, TailwindCSS and Firebase.
